Every group uses the same parameters, evaluation minibatches, and evaluation-mode BatchNormbuffers. The intervention is applied **during recurrent forward dynamics**, and its output iswritten back to the membrane state before reset. It can therefore change later spikes andfiring rates. This is not post-processing of a fixed spike trace.
The original identity-gradient intervention convention is explicit. For intervened rows,`smooth_gradient_is_objective_gradient=False` unless `--intervention-gradient exact` is chosenthe reset derivative is complete, and no singular zero margin is detected. Intervened backward-map comparisons are not silentlypresented as exact gradients of the modified objective. At a zero margin, a non-unit powerintervention can be nonsmooth; exact mode uses a documented zero subgradient there.
## Mathematical conventions and files
- Hard spikes: `1[u > 0]`, including a silent spike at exactly zero margin.- ATan smooth spike: `1/2 + atan(pi*alpha*u/(2*delta))/pi`.- LocalZO noise: scaled Student-t with 3 degrees of freedom, normalized by its second moment.- Reset: hard reset to zero; **full reset derivative by default**. The optional  `--detach-reset` variant is explicitly labeled and does not yield the full smooth-objective gradient.- `backward_mismatch_sq` squares the sample-weighted mean gradient difference, retaining  all parameter coordinates. It is not the mean of per-batch squared differences.- `tail_diagnostic` is the per-node average; `tail_sum_per_sample` preserves the graph-size factor.
Each run produces `metadata.json`, `training.csv`, `diagnostics.csv`, `best.pt`, and `last.pt`.Metadata records actual wall-clock seconds, GPU-hours, device count, peak allocated CUDAmemory, seed, model specification, optimizer settings, and data kind. The timer covers training,validation, probes, and checkpoint writing after dataset initialization. CPU runs report zeroGPU-hours. This records new runs; it cannot reconstruct historical compute usage.
Checkpoint loading uses `weights_only=True` and a versioned schema. Legacy Lightningcheckpoints are rejected rather than loaded with guessed key mappings.
